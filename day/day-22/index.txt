<div class="warn"><b>Near-pair contrasts, taught explicitly (VI-7).</b><br/>
<b>① <span class="hz">本</span> vs <span class="hz">个</span> vs <span class="hz">件</span>.</b> Books take <span class="hz">本</span>; clothes take <span class="hz">件</span>; nearly everything else you own takes <span class="hz">个</span> — including <span class="hz">桌子</span>, <span class="hz">椅子</span> and <span class="hz">电脑</span>. <span class="hz">一本书</span> ✓, <span class="hz">一个书</span> ✗.<br/>
<b>② <span class="hz">三个月</span> vs <span class="hz">三天</span> vs <span class="hz">三年</span>.</b> Only <span class="hz">月</span> needs <span class="hz">个</span>. This is not a pattern you can reason your way to — it just is, and it is worth over-practising.<br/>
<b>③ <span class="hz">一半</span> vs <span class="hz">半</span>.</b> <span class="hz">半</span> alone lives inside a clock time: <span class="hz">两点半</span>. <span class="hz">一半</span> is “half of a thing”: <span class="hz">读一半</span>. You would not say <span class="hz">两点一半</span>.<br/>
<b>④ <span class="hz">第一</span> vs <span class="hz">一</span>.</b> One is an order, the other a count. <span class="hz">一本书</span> is one book; <span class="hz">第一本书</span> is the first book. And note the sound: <span class="hz">一本</span> is said <span class="py">yìběn</span>, but <span class="hz">第一</span> keeps <span class="py">yī</span> — ordinals are one of the sandhi exceptions.</div>10:T109b,<p class="lead">Two points, both short. G43 is a politeness device you will use constantly; G58 is the last of the number grammar and the highest-numbered point the course will teach.</p>
<div class="card learn">
<div class="exhead"><span class="pill">G43</span><span class="exname">Verb + 一下 (do briefly)</span><span class="extitle">difficulty: core · prerequisite: G14 (Day 5)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">你看。</span> is “Look.” — an instruction. <span class="hz">你看一下。</span> is “Have a look.” — an invitation. Two syllables turn an order into a request, and Chinese uses them constantly.</p>
<p><b>The rule.</b> Put <span class="hz">一下</span> straight after the verb. If there is an object, it goes after <span class="hz">一下</span>. Nothing else changes.</p>
<div class="grule"><div class="pat">Verb + 一下 (+ Object)</div><div class="ex">看一下 · 问一下 · 说一下 · 看一下这本书 · 问一下老师</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">你看一下这本书。</div><div class="ex"><span class="py">Nǐ kàn yīxià zhè běn shū.</span> “Have a look at this book.” — a request, not a command.</div></div>
<div class="grule"><div class="pat">我想问一下。</div><div class="ex"><span class="py">Wǒ xiǎng wèn yīxià.</span> “I’d like to ask something.” — the standard polite opener, and it stacks under <span class="hz">想</span> without any change.</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">看一下这本书</span> ✓ vs <span class="hz">看这本书一下</span> ✗ — <span class="hz">一下</span> attaches to the verb and cannot be pushed past the object. And compare <span class="hz">请问</span> from Day 4: that is a fixed phrase for opening a question, while <span class="hz">问一下</span> is productive and works on any verb you know.</p>
<div class="note"><b>Why this matters more than it looks.</b> Chinese has no “please” that attaches to verbs the way English does. Softening is done structurally — with <span class="hz">一下</span>, with <span class="hz">请</span>, with question form. This is the most portable of the three.</div>
</div>

<div class="card learn">
<div class="exhead"><span class="pill">G58</span><span class="exname">Ordinal numbers with 第</span><span class="extitle">difficulty: core · prerequisite: G16 (Day 7)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">一课</span> would be “one lesson”. <span class="hz">第一课</span> is “Lesson One”. One character in front converts a count into a position in a sequence.</p>
<p><b>The rule.</b> Put <span class="hz">第</span> in front of the number. Everything after it behaves normally — including the measure word, which does not disappear.</p>
<div class="grule"><div class="pat">第 + Number (+ Measure Word) + Noun</div><div class="ex">第一 · 第二本 · 第三个 · 第一本书 · 第二件衣服</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">这是第一本，我想买第二本。</div><div class="ex"><span class="py">Zhè shì dì-yī běn, wǒ xiǎng mǎi dì-èr běn.</span> “This is the first one; I want to buy the second.”</div></div>
<div class="grule"><div class="pat">我住第三个房间。</div><div class="ex"><span class="py">Wǒ zhù dì-sān ge fángjiān.</span> “I live in the third room.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">第二本</span> ✓ vs <span class="hz">第两本</span> ✗ — ordinals always use <span class="hz">二</span>, never <span class="hz">两</span>.
