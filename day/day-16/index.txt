<div class="card learn">
<div class="exhead"><span class="pill">G33</span><span class="exname">Position words (上/下/里/外/前/后 + 边)</span><span class="extitle">difficulty: core · prerequisite: G31 (Day 15)</span></div>
<div class="exbody">
<p><b>Notice first.</b> Yesterday you could only say <span class="hz">在家里</span> as a fixed phrase. Today: <span class="hz">在学校里</span>, <span class="hz">在医院外边</span>, <span class="hz">在公司前边</span> — any noun, any position word.</p>
<p><b>The rule.</b> A position word goes <b>after</b> the noun it locates. That is the opposite of English, which puts it in front. <span class="hz">边</span> may be added to make the position word a full place noun; with <span class="hz">里</span> and <span class="hz">上</span> it is usually left off.</p>
<div class="grule"><div class="pat">Noun + 上 / 下 / 里 / 外 / 前 / 后 (+ 边)</div><div class="ex">学校里 · 医院外边 · 学校后边 · 公司前边 · 家里</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">我在学校里。</div><div class="ex"><span class="py">Wǒ zài xuéxiào li.</span> “I’m in the school.” — <span class="hz">学校</span> first, then the position.</div></div>
<div class="grule"><div class="pat">医院在学校后边。</div><div class="ex"><span class="py">Yīyuàn zài xuéxiào hòubian.</span> “The hospital is behind the school.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">学校里</span> ✓ vs <span class="hz">里学校</span> ✗ — English says “in the school”, Chinese says “school-in”. And <span class="hz">在学校后边</span> ✓ vs <span class="hz">在后边学校</span> ✗.</p>
<div class="note"><b>Three tags released.</b> <span class="hz">里 · 外 · 前</span> were introduced yesterday inside fixed frames because this rule had not arrived. It has now. All three are fully productive from this point, and <span class="hz">后</span> joins them today.</div>

<div class="card learn">
<div class="exhead"><span class="pill">G34</span><span class="exname">Place pronouns 这儿 / 那儿 / 这里 / 那里</span><span class="extitle">difficulty: core · prerequisites: G9 (Day 3) · G31 (Day 15)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">这是我的手机。</span> points at a thing. <span class="hz">我在这儿。</span> points at a place. One syllable makes the difference.</p>
<p><b>The rule.</b> <span class="hz">这</span> and <span class="hz">那</span> become places when you add <span class="hz">儿</span> or <span class="hz">里</span>. The resulting words behave like any other place noun — they follow <span class="hz">在</span>, and they answer <span class="hz">在哪儿？</span> or <span class="hz">在哪里？</span>.</p>
<div class="grule"><div class="pat">在 + 这儿 / 这里 / 那儿 / 那里  ·  在哪儿？ / 在哪里？</div><div class="ex">我在这儿。 / 老师在那里。 / 你的同学在哪儿？</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">老师在那儿。</div><div class="ex"><span class="py">Lǎoshī zài nàr.</span> “The teacher is over there.”</div></div>
<div class="grule"><div class="pat">你的同学在哪里？——他在这里。</div><div class="ex"><span class="py">Nǐ de tóngxué zài nǎlǐ? —— Tā zài zhèlǐ.</span> “Where’s your classmate? — He’s here.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">我在这儿。</span> ✓ vs <span class="hz">我在这。</span> ✗ — bare <span class="hz">这</span> cannot be a place. And note the question word you already own: <span class="hz">哪儿</span> and <span class="hz">哪里</span> (Day 5) are built the same way from <span class="hz">哪</span>.</p>
<div class="note"><b>The whole family, one table.</b> <span class="hz">这</span> · <span class="hz">那</span> · <span class="hz">哪</span> each take the same four endings: <span class="hz">个</span> for an item, <span class="hz">儿</span> and <span class="hz">里</span> for a place, <span class="hz">边</span> for a side. <p><b>Where the tone mark goes (PS-7).</b> Because the middle vowel is not written, these two finals break the usual “mark the main vowel” habit.
