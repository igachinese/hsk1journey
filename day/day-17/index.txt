<div class="warn"><b>Near-pair contrasts, taught explicitly (VI-7).</b><br/>

<div class="card learn">
<div class="exhead"><span class="pill">G36</span><span class="exname">Intention with 想 + Verb</span><span class="extitle">difficulty: core · prerequisite: G14 (Day 5)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">我上学。</span> is what you do. <span class="hz">我想上学。</span> is what you would like to do. One word in front of the verb changes a fact into a plan.</p>
<p><b>The rule.</b> <span class="hz">想</span> goes directly before the verb, in the same slot as <span class="hz">会</span>, <span class="hz">能</span> and <span class="hz">可以</span>. Negate with <span class="hz">不想</span>. Ask with <span class="hz">想……吗？</span>.</p>
<div class="grule"><div class="pat">Subject + 想 + Verb (+ Object)  ·  Subject + 不想 + Verb</div><div class="ex">我想上学。 / 我想来学校。 / 我不想上课。</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">我想来你们学校。</div><div class="ex"><span class="py">Wǒ xiǎng lái nǐmen xuéxiào.</span> “I’d like to come to your school.”</div></div>
<div class="grule"><div class="pat">我今天不想上课。</div><div class="ex"><span class="py">Wǒ jīntiān bù xiǎng shàngkè.</span> “I don’t feel like going to class today.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">我想上学。</span> ✓ (I want to go to school) vs <span class="hz">我会上学。</span> — a different claim entirely, and vs <span class="hz">我上学想。</span> ✗ — the modal never follows its verb.</p>

<div class="card learn">
<div class="exhead"><span class="pill">G37</span><span class="exname">会 for future likelihood</span><span class="extitle">difficulty: core · prerequisite: G12 (Day 5)</span></div>
<div class="exbody">
<p><b>Notice first.</b> On Day 5 you learned <span class="hz">我会说汉语。</span> — a learned skill. Now: <span class="hz">明天会很忙。</span> — nothing has been learned; this is a prediction.</p>
<p><b>The rule.</b> The same <span class="hz">会</span>, the same slot, a second meaning: <b>it will probably happen</b>. Which meaning is in play is decided by what follows. A skill verb after <span class="hz">会</span> means “know how to”; a state or event after it means “will”.</p>
<div class="grule"><div class="pat">Subject + 会 + Verb / 很 + Adjective  ·  Subject + 不会 + …</div><div class="ex">明天会很忙。 / 他会来。 / 他不会来。</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">明天会很忙。</div><div class="ex"><span class="py">Míngtiān huì hěn máng.</span> “Tomorrow will be busy.”</div></div>
<div class="grule"><div class="pat">他明天不会来。</div><div class="ex"><span class="py">Tā míngtiān bù huì lái.</span> “He won’t come tomorrow.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">我会说汉语。</span> = I can speak Chinese (skill). <span class="hz">他会来。</span> = He’ll come (prediction). Same word, and only the rest of the sentence tells you which.</p>
