<div class="warn"><b>Near-pair contrasts, taught explicitly (VI-7).</b><br/>
<b>① <span class="hz">读</span> vs <span class="hz">看</span> vs <span class="hz">读书</span>.</b> <span class="hz">看</span> (yesterday) is looking at anything. <span class="hz">读</span> is reading text, often aloud. <span class="hz">读书</span> is being a student. <span class="hz">我看这件衣服。</span> · <span class="hz">我读这些书。</span> · <span class="hz">我在大学读书。</span><br/>
<b>② <span class="hz">有些</span> vs <span class="hz">有的</span> vs <span class="hz">一些</span>.</b> <span class="hz">一些</span> is a plain quantity — “some, a few” — and can follow a verb: <span class="hz">买一些苹果</span>. <span class="hz">有些</span> and <span class="hz">有的</span> pick out part of a known group and start the sentence: <span class="hz">有些书很贵。</span> You would not say <span class="hz">买有些苹果</span>.<br/>
<b>③ <span class="hz">这些</span> vs <span class="hz">这个</span>.</b> Number, nothing else. One or many. Both point at the same kind of thing.<br/>

G41 is a single word that takes a whole sentence as its object — the first time the course has done that. G42 tidies a family you have been half-using since Day 5.</p>
<div class="card learn">
<div class="exhead"><span class="pill">G41</span><span class="exname">Opinions with 觉得</span><span class="extitle">difficulty: core · prerequisite: G10 (Day 4)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">大学很好。</span> is a claim about the world. <span class="hz">我觉得大学很好。</span> is a claim about what <em>you</em> think. The second one invites disagreement; the first does not.</p>
<p><b>The rule.</b> <span class="hz">觉得</span> is followed by a complete sentence — subject and predicate, exactly as it would stand on its own. Nothing joins them: no “that”, no comma, no particle.</p>
<div class="grule"><div class="pat">Subject + 觉得 + [a whole sentence]</div><div class="ex">我觉得大学很好。 / 我觉得这些书很贵。 / 他觉得读书很好。</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">我觉得这些书很贵。</div><div class="ex"><span class="py">Wǒ juéde zhèxiē shū hěn guì.</span> “I think these books are expensive.” — <span class="hz">这些书很贵</span> is a complete sentence in its own right.</div></div>
<div class="grule"><div class="pat">我不觉得贵。</div><div class="ex"><span class="py">Wǒ bù juéde guì.</span> “I don’t think it’s expensive.” — the <span class="hz">不</span> goes on <span class="hz">觉得</span>, not inside the opinion.</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">我觉得大学很好。</span> ✓ vs <span class="hz">我觉得大学好。</span> — the second drops <span class="hz">很</span> and so reads as a comparison, exactly the Day-4 rule working inside the embedded sentence. And <span class="hz">我不觉得贵。</span> ✓ vs <span class="hz">我觉得不贵。</span> ✓ — both exist and differ in emphasis, the first denying the opinion and the second stating a negative one.</p>
<div class="note"><b>Your sentences can now contain sentences.</b> Everything before today was one clause with one predicate. <span class="hz">觉得</span> opens a slot that swallows a whole clause, and that is a structural step up, not just a new word.</div>

<div class="card learn">
<div class="exhead"><span class="pill">G42</span><span class="exname">Quantifiers 些 / 一些 / 这些 / 那些</span><span class="extitle">difficulty: core · prerequisite: G17 (Day 7)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">这个书</span> is one book. But you cannot say <span class="hz">三个这个书</span> for three of them — for an unspecified plural, Chinese uses <span class="hz">些</span>, and the measure word disappears.</p>
<p><b>The rule.</b> <span class="hz">些</span> marks an unspecified plural amount. It attaches to <span class="hz">一</span>, <span class="hz">这</span>, <span class="hz">那</span>, <span class="hz">哪</span> or <span class="hz">有</span>, and the resulting word goes straight in front of the noun with <b>no measure word</b>.</p>
<div class="grule"><div class="pat">一些 / 这些 / 那些 / 有些 + Noun  ·  有的 + (Noun) …，有的 + (Noun) …</div><div class="ex">一些苹果 · 这些书 · 那些人 · 有些书 · 有的是我的，有的是他的</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">这些书都是我的。</div><div class="ex"><span class="py">Zhèxiē shū dōu shì wǒ de.</span> “These books are all mine.” — <span class="hz">都</span> from Day 10 pairs naturally with a plural.</div></div>
<div class="grule"><div class="pat">有的很贵，有的很便宜。</div><div class="ex"><span class="py">Yǒude hěn guì, yǒude hěn piányi.</span> “Some are expensive, some are cheap.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">这些书</span> ✓ vs <span class="hz">这些个书</span> ✗ — the measure word cannot survive alongside <span class="hz">些</span>.
