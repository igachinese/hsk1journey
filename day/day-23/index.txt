<div class="warn"><b>Near-pair contrasts, taught explicitly (VI-7).</b><br/>
<b>① <span class="hz">雨</span> vs <span class="hz">下雨</span>.</b> One is a noun, one is a verb. <span class="hz">雨很大。</span> = “The rain is heavy.” <span class="hz">今天下雨。</span> = “It’s raining today.” You cannot say <span class="hz">今天雨。</span><br/>
<b>② <span class="hz">有点儿冷</span> vs <span class="hz">很冷</span>.</b> Both are positive statements about cold. <span class="hz">很冷</span> is neutral — a plain report. <span class="hz">有点儿冷</span> adds a note of complaint: it’s a bit too cold. This is a real difference in feeling and tomorrow’s grammar section treats it as a rule, not a nuance.<br/>
<b>③ <span class="hz">日</span> vs <span class="hz">号</span> vs <span class="hz">天</span>.</b> <span class="hz">日</span> and <span class="hz">号</span> both name a calendar date; <span class="hz">天</span> counts days as a duration. <span class="hz">十八日</span> is the eighteenth; <span class="hz">十八天</span> is eighteen days.<br/>
<b>④ <span class="hz">去年</span> vs <span class="hz">昨天</span>.</b> The “previous” words do not match. <span class="hz">昨</span> works for days only; <span class="hz">去</span> works for years only. There is no <span class="hz">昨年</span> and no <span class="hz">去天</span>.<br/>
<b>⑤ <span class="hz">怎么样</span> vs <span class="hz">吗</span>.</b> <span class="hz">贵吗？</span> offers a candidate answer and asks yes or no. <span class="hz">怎么样？</span> offers nothing and invites any answer. Use the second when you truly do not know.</div>10:T1aa5,<p class="lead">Three points, the maximum the system allows in one day (G-04). They are sequenced easiest first: an open question word, then a degree adverb, then the date convention that needs both numbers and units.</p>
<div class="card learn">
<div class="exhead"><span class="pill">G44</span><span class="exname">Weather &amp; 怎么样</span><span class="extitle">difficulty: core · prerequisite: G10 (Day 4)</span></div>
<div class="exbody">
<p><b>Notice first.</b> Weather sentences need no verb. <span class="hz">今天很冷。</span> is a complete sentence — “Today is very cold” — and the word for “is” never appears, because <span class="hz">冷</span> is doing the predicate’s job. That is the Day-4 adjective rule, applied to a new topic.</p>
<p><b>The rule.</b> Describe weather with an adjectival predicate. Ask about it with <span class="hz">怎么样</span>, which goes exactly where the answer would go — at the end, after the topic.</p>
<div class="grule"><div class="pat">(Time) + 天气 + 很 / 不 + Adjective  ·  (Time) + 天气 + 怎么样？</div><div class="ex">今天天气很好。 / 今天很冷。 / 今天天气怎么样？ / 这本书怎么样？</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">今天天气怎么样？ —— 今天很冷。</div><div class="ex"><span class="py">Jīntiān tiānqì zěnmeyàng? —— Jīntiān hěn lěng.</span> The question leaves the adjective open; the answer supplies it.</div></div>
<div class="grule"><div class="pat">今天下雨，雨很大。</div><div class="ex"><span class="py">Jīntiān xiàyǔ, yǔ hěn dà.</span> A weather verb and a weather noun in one line.</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">今天天气怎么样？</span> ✓ vs <span class="hz">今天天气很怎么样？</span> ✗ — <span class="hz">怎么样</span> is not an adjective and never takes <span class="hz">很</span>. And <span class="hz">今天很冷。</span> ✓ vs <span class="hz">今天是很冷。</span> ✗ — <span class="hz">是</span> and an adjective do not co-occur.</p>
<div class="note"><b><span class="hz">怎么样</span> works far beyond weather.</b> <span class="hz">这本书怎么样？</span>, <span class="hz">那个店怎么样？</span>, <span class="hz">明天怎么样？</span> — anything you could have an opinion about. Combined with Day 21’s <span class="hz">觉得</span>, you can now both ask for an opinion and give one.</div>

<div class="card learn">
<div class="exhead"><span class="pill">G45</span><span class="exname">有点儿 + Adjective (a bit)</span><span class="extitle">difficulty: core · prerequisite: G10 (Day 4)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">很冷</span> reports. <span class="hz">有点儿冷</span> complains. The grammar is a straight swap — <span class="hz">有点儿</span> takes the slot <span class="hz">很</span> occupies — but the meaning shifts in a direction English speakers do not expect.</p>
<p><b>The rule.</b> <span class="hz">有点儿</span> goes directly before the adjective, in place of <span class="hz">很</span>. The two never appear together. It signals a slight degree and, in almost every natural use, one the speaker is not happy about.</p>
<div class="grule"><div class="pat">Subject + 有点儿 + Adjective</div><div class="ex">今天有点儿冷。 / 这本书有点儿贵。 / 房间有点儿小。</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">今天有点儿热。</div><div class="ex"><span class="py">Jīntiān yǒudiǎnr rè.</span> “It’s a bit hot today.” — with the implication that this is unwelcome.</div></div>
<div class="grule"><div class="pat">这件衣服有点儿贵。</div><div class="ex"><span class="py">Zhè jiàn yīfu yǒudiǎnr guì.</span> “This is a bit expensive.” — the polite way to say no in a shop.</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">有点儿贵</span> ✓ vs <span class="hz">有点儿便宜</span> ✗ in ordinary use — cheapness is welcome, so it does not take a complaint marker. Say <span class="hz">很便宜</span>. And <span class="hz">很有点儿冷</span> ✗ — one degree word per adjective.</p>
<div class="note"><b>This is a politeness tool, not just a degree word.</b> <span class="hz">这件衣服有点儿贵。</span> declines a purchase without saying no, without naming a figure, and without insulting the shop. It is one of the most useful sentences in this course.</div>

<div class="exhead"><span class="pill">G46</span><span class="exname">Dates: 年 / 月 / 日 (号)</span><span class="extitle">difficulty: core · prerequisites: G16 (Day 7) · G23 (Day 10)</span></div>
<div class="exbody">
<p><b>Notice first.</b> Chinese dates run largest to smallest — year, then month, then day. English runs in two different orders depending on which country you are in; Chinese has exactly one, and it never varies.</p>
<p><b>The rule.</b> Read the year digit by digit, then the month as a plain number plus <span class="hz">月</span>, then the day as a plain number plus <span class="hz">日</span> or <span class="hz">号</span>. Nothing joins the three units.</p>
<div class="grule"><div class="pat">Year (digit by digit) + 年 + Number + 月 + Number + 日 / 号</div><div class="ex">二零二六年 · 六月 · 十八日 → 二零二六年六月十八日</div></div>

<div class="grule"><div class="pat">今天是六月十八日。</div><div class="ex"><span class="py">Jīntiān shì liù yuè shíbā rì.</span> “Today is the eighteenth of June.” Note that dates <em>do</em> take <span class="hz">是</span>, unlike adjectives.</div></div>
<div class="grule"><div class="pat">二零二六年六月十八日</div><div class="ex"><span class="py">Èr líng èr liù nián liù yuè shíbā rì.</span> The year is read as four separate digits — never as “two thousand and twenty-six”.</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">六月</span> = June (the sixth month) vs <span class="hz">六个月</span> = six months.
