<div class="warn"><b>Near-pair contrasts, taught explicitly (VI-7).</b><br/>
<b>① <span class="hz">几</span> vs <span class="hz">多少</span>.</b> <span class="hz">几</span> asks about a small, expected count and <em>always</em> takes a measure word: <span class="hz">几个人？</span> <span class="hz">几口人？</span> <span class="hz">几岁？</span> <span class="hz">多少</span> asks about an open or large amount and takes <em>no</em> measure word: <span class="hz">你的电话是多少？</span> If you can guess the answer is under ten, use <span class="hz">几</span>.<br/>
<b>② <span class="hz">能</span> vs <span class="hz">可以</span>.</b> <span class="hz">能</span> is about <em>capacity</em> — you are physically or practically able. <span class="hz">可以</span> is about <em>permission</em> — it is allowed, it’s fine. <span class="hz">我能给你打电话。</span> (I’m able to.) · <span class="hz">我可以给你打电话吗？</span> (May I?) <div class="card learn">
<div class="exhead"><span class="pill">G25</span><span class="exname">多少 vs 几 (how much / how many)</span><span class="extitle">difficulty: core · prerequisite: G18 (Day 8)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">你家几口人？</span> — small, countable. <span class="hz">你的电话是多少？</span> — open, unknown.</p>
<p><b>The rule.</b> <span class="hz">多少</span> asks for a larger or unknown amount and stands alone, with <b>no measure word</b>. <span class="hz">几</span> asks for a small expected count and <b>always</b> carries one. Neither ever takes <span class="hz">吗</span>.</p>
<div class="grule"><div class="pat">多少 + (Noun)  ·  几 + Measure Word + Noun</div><div class="ex">电话是多少？ · 多少人？  |  几个人？ · 几口人？ · 几岁？</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">你的电话是多少？</div><div class="ex"><span class="py">Nǐ de diànhuà shì duōshao?</span> “What’s your phone number?”</div></div>
<div class="grule"><div class="pat">你有几个问题？</div><div class="ex"><span class="py">Nǐ yǒu jǐ ge wèntí?</span> “How many questions do you have?”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">多少人？</span> ✓ vs <span class="hz">多少个人？</span> ✗ · <span class="hz">几个人？</span> ✓ vs <span class="hz">几人？</span> ✗ — the measure word is obligatory for one and forbidden for the other.</p>

<div class="card learn">
<div class="exhead"><span class="pill">G26</span><span class="exname">Modals 能 / 可以 (can, may)</span><span class="extitle">difficulty: core · prerequisite: G12 (Day 5)</span></div>
<div class="exbody">
<p><b>Notice first.</b> You already say <span class="hz">我会说汉语。</span> — learned skill. Now: <span class="hz">我能给你打电话。</span> — able to. <span class="hz">我可以问你吗？</span> — allowed to.</p>
<p><b>The rule.</b> <span class="hz">能</span> and <span class="hz">可以</span> sit in the same slot as <span class="hz">会</span>: directly before the verb. Negate either with <span class="hz">不</span>. <span class="hz">能</span> = capacity; <span class="hz">可以</span> = permission.</p>
<div class="grule"><div class="pat">Subject + 能 / 可以 + Verb (+ Object)</div><div class="ex">我能打电话。 / 你可以问老师。 / 我不能给你打电话。</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">我能给你打电话。</div><div class="ex"><span class="py">Wǒ néng gěi nǐ dǎ diànhuà.</span> “I can call you.” — I’m able to.</div></div>
<div class="grule"><div class="pat">你可以问老师。</div><div class="ex"><span class="py">Nǐ kěyǐ wèn lǎoshī.</span> “You may ask the teacher.” — it’s allowed.</div></div>
<p><b>Minimal contrast (GE-4):</b> three modals, three jobs — <span class="hz">我会说汉语。</span> (learned it) · <span class="hz">我能说汉语。</span> (able to right now) · <span class="hz">我可以说汉语。</span> (permitted to).</p>
</div>

<div class="card learn">
<div class="exhead"><span class="pill">G27</span><span class="exname">给 + person + Verb</span><span class="extitle">difficulty: core · prerequisite: G14 (Day 5)</span></div>
<div class="exbody">
<p><b>Notice first.</b> <span class="hz">我打电话。</span> → <span class="hz">我给妈妈打电话。</span> The person you are calling goes <em>before</em> the verb, not after it.</p>
<p><b>The rule.</b> <span class="hz">给</span> + the person marks who the action is <em>for</em>, and the whole phrase sits between the subject and the verb — the same zone as time words and <span class="hz">也</span>/<span class="hz">都</span>. English puts the person last; Chinese puts them first.</p>
<div class="grule"><div class="pat">Subject + 给 + Person + Verb (+ Object)</div><div class="ex">我给妈妈打电话。 / 请给我打电话。 / 他今天给我打电话。</div></div>
<p><b>Two examples:</b></p>
<div class="grule"><div class="pat">我给妈妈打电话。</div><div class="ex"><span class="py">Wǒ gěi māma dǎ diànhuà.</span> “I’m calling my mum.”</div></div>
<div class="grule"><div class="pat">请给我打电话。</div><div class="ex"><span class="py">Qǐng gěi wǒ dǎ diànhuà.</span> “Please call me.”</div></div>
<p><b>Minimal contrast (GE-4):</b> <span class="hz">我给他打电话。</span> ✓ vs <span class="hz">我打电话给他。</span> ✗ at this level — keep the recipient in front of the verb.</p>
<div class="note"><b>Slot order, cumulative.</b> Subject → time → <span class="hz">也/都</span> → <span class="hz">给</span> + person → modal → verb. <span class="hz">我今天也可以给他打电话。</span> Every piece of that is a rule you already own.</div>

<p><b>Two examples:</b></p>
